The supplied CyTrace UE 5.3 build validates a version-11 Pak and version-5 IoStore TOCs/UCAS files: all 1,518 live Pak members and 4,696 IoStore chunks decode and match an independent container reader in the current shipping corpus. Zen validation additionally reads 3,507 cooked package headers and 7,502 exports, resolves 31,616 global script objects and locates opaque body changes by object. Supported unversioned property values now have synthetic fixture coverage with explicit mappings; selected real texture property streams now decode with generated matching-source mappings, while broader mapped values and native payload semantics remain open. No pre-existing `.usmap` was found in the project tree. Source projects, containers, assets and generated reports remain outside Git. See [container contracts](CONTAINERS.md) and [cooked Zen contracts](ZEN.md) and [schema contracts](SCHEMAS.md).

Declarative native layouts are supplied by the host and validated against original bounded fixtures. They do not automatically extract serializers from an installed engine, parse arbitrary plugin C++ or decode Nanite/cooked-skin/compressed-animation payloads. The matching-build real USMAP limitation above remains. See [native layout and string contracts](BINARY_LAYOUTS.md).

Modern skeletal MeshDescription support is fixture-validated. The available real older skeletal mesh has no matching modern source object, so real modern skeletal coverage remains unverified. See [source skinning contracts](SKINNING.md).

Modern source morph decoding is fixture-validated, with an installed Core-only example and bilingual typed inspection. Real independently produced morph sources, cooked/legacy morph buffers and runtime blend/skin evaluation remain unverified or unimplemented. See [source morph contracts](MORPHS.md).

Serialized native reflection prefixes now expose declared fields from supported Blueprint-generated classes/functions and selected struct families. An independent Python reader matches 123 real declarations from 33 authorized editor assets. These definitions do not resolve inheritance/defaults or reveal arbitrary plugin serializers, and cooked schema derivation remains open. See [field declarations](REFLECTION.md).

Optional UE 5.3 UHT metadata preparation now generates native mappings from the selected source/build context. Real validation decodes 21 selected cooked texture property streams and matches 39 comparable values to loose sources. Sparse unknown descriptors, unresolved static dimensions, Blueprint composition and arbitrary native serializers remain explicit limits. See [matching-source contracts](UHT_SCHEMAS.md).

Explicit UE 5.3 cooked Texture2D BulkData windows now expose verified inline/external mips and 15 raw/BC pixel formats in Core, CLI and EN/FR desktop, including full-precision/HDR comparison, all prepared mip selections and workspace retention. Independent real evidence covers 21 textures and 107 mipmaps. Cooked virtual textures, newer native profiles, console packing and other cooked asset families remain open. See [cooked pixel contracts](COOKED_TEXTURES.md).

Matching-source preparation also accepts exact metadata-bound static dimension facts and resolves UHT LWC double properties. The selected UV-array count enables all 84 real StaticMesh property streams; 3,119 common type/value/count checks match loose sources. Cooked geometry remains the next native reader rather than being inferred from those schemas. See [UHT_SCHEMAS.md](UHT_SCHEMAS.md).

Stored editor-bulk transient state no longer hides valid local mesh sources. All 84 selected real MeshDescription sources, containing 106,627 triangles, decode through CLI and an installed Core-only consumer with full raw BLAKE3 verification. Independent cooked-buffer correspondence is established for the first selected render LOD; a public cooked geometry reader and broader correspondence remain in progress.
