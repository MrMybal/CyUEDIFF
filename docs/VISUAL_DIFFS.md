# Visual comparisons

CyUEDiff 0.12 prepares comparison models outside the render loop. The Core exposes `visual_diff.hpp` without a dependency on CyUI; `CyUEDiff::UI` adds the themed views. English is the default and French is included.

- Blueprint graphs use graph/node/pin identities from the semantic snapshot. Changed nodes receive a colored body outline. Adding, removing or modifying a connection marks its endpoint nodes too. Counts cover the union of both revisions; switch Before/After to see nodes present on that side.
- Material expression graphs use the same outline behavior. Instance tables pair parameters by kind, association, index and name, and display stored values and override flags for both revisions. Parent values and shaders are not evaluated.
- Source mesh previews pair stable MeshDescription vertex, instance and triangle IDs. Added edges are green, removed edges red, and modified edges amber. Changes to positions, triangle topology, UVs, normals, tangents, colors and referenced material slots affect the incident edges. A saved-ID match does not establish geometric correspondence after a tool regenerates IDs. The preview remains capped at 100,000 edges.
- Texture previews pair equal object paths, or the sole decoded texture on each side. The difference mask is selected initially; uncheck **Pixel difference mask** for the source. Red opaque pixels changed; transparent pixels did not. Statistics compare encoded RGBA8 samples with threshold zero, including alpha, without a color-space transform. Different dimensions are explicitly incomparable. The desktop currently decodes the first texture and first mesh source/LOD on each side.
- The property inspector shows type, before/after value and change state. Search by property path/type or select **Changed only**. Paths use JSON Pointer escaping. Unknown/opaque metadata remains inspectable; **Raw JSON** preserves access to the original view. Display limits are 20,000 rows, 48 levels and bounded string previews, with an explicit truncation notice.

For embedders, `BlueprintView::set_package(package, peer, after)` and `MaterialView::set_package(package, peer, after)` accept an optional comparison package. `MeshView::set_mesh(mesh, peer, after, comparing)` accepts decoded source geometry. `AssetView` prepares both graph sides from `set_packages`; the host supplies CPU-decoded geometry and GPU image resources as before. `set_texture_difference(before_path, after_path, image, comparison)` binds a host-owned mask and retains only scalar statistics. Clear views before releasing GPU resources. None of the views writes an Unreal package.
